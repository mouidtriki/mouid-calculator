# c2n-calculator-template

A small calculator, written by your group, one file each.

`calculator.py` is finished. **DO NOT EDIT IT**. It runs a demo that uses four files, and tells you which ones are still missing. If Python is installed, you can run `calculator.py` from your editor to see it.

## The four files

One file per person, in the same folder as `calculator.py`. The function name must match the file name.

- `add.py`: `def add(a, b)` returns a + b
- `subtract.py`: `def subtract(a, b)` returns a - b
- `multiply.py`: `def multiply(a, b)` returns a * b
- `divide.py`: `def divide(a, b)` returns a / b. When b is 0, return `None` instead of crashing.

A file looks like this (this one is not on the list, it only shows the shape):

```python
def double(x):
    return x * 2
```

## Your turn

1. Pick one file from the list. One person per file.
2. Create it in this folder and write the function.
3. Add your line to the list at the bottom of this README.
4. Commit, !PULL! then push. If GitHub Desktop says someone pushed before you, pull first, then push.

## Stretch

When all four files work, create a branch called `power`. On that branch, add `power.py` with `def power(a, b)` that returns a to the power b. Push the branch, then open a pull request on GitHub for someone else in your group to review.
